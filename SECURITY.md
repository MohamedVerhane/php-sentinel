# Security Policy

## Supported versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a vulnerability

PHP Sentinel is a static analysis tool; it does **not** execute scanned source
code. That said, if you discover a security issue in the tool itself (for
example, unsafe handling of untrusted paths, denial-of-service via crafted
input, or an issue that could compromise the environment running the scanner),
please **do not** open a public issue.

Report it privately to the maintainers by emailing:

**security@example.invalid**

(Replace this address with the project maintainer's security contact before
releasing.)

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce, including any relevant input that triggers the problem.
- The versions affected, if known.

You should receive an acknowledgement within 3 business days. We ask that you
keep details of any confirmed vulnerability private until a fix is released.

## Policy

- We will acknowledge receipt of valid reports promptly.
- We will investigate and, if confirmed, work toward a fix in a timely manner.
- We will credit reporters (unless they prefer to remain anonymous).
